📖 Guide

Core Features

Create new notes, search powerfully, auto-tag with #tags, sort dynamically, and color-code notes.

Smart Rules

Define regex patterns that automatically apply titles, colors, templates and reminders when matched in your notes. Use capture groups like $1 in your templates.

Productivity

Use the context menu to quick-capture web text. Enable the global shortcut to launch anytime. Save notes silently in the background.

Note Linking

Type [[note-title]] in any note to instantly link to or cross-reference other existing notes.

Reminders

Set precise date/time reminders for follow-ups. Customize notification actions like snooze or auto-dismiss.

Keyboard Shortcuts

  • Alt + N : New Note
  • Alt + S : Search
  • Esc : Cancel/Close
