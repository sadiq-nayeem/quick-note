📖 Guide

Core Features

Create new notes, search powerfully, manage folders, auto-tag with #tags, sort dynamically, and color-code notes.

Smart Rules & Automation

Define regex patterns (e.g. CL-(\d+)) that automatically apply formatting and actions when matched in your notes. Use capture groups like $1 in your templates.

  • Formatting: Auto-set titles, comment templates, or colors.
  • Organization: Auto-assign to a specific Folder or apply auto-tags (e.g. #jira-$1).
  • Actions: Auto-pin to the top (📌), mark as favorite (⭐), or set recurring reminders.
  • Site Pinning: Auto-pin notes to specific websites (e.g. github.com) so they appear first when you visit that site.

Advanced Rule Editing ({ } JSON)

For tech-savvy users, click the { } JSON button in the Smart Rules editor to manage rules in raw JSON format. Perfect for bulk editing, backing up rules, or sharing rulesets with your team.

Example JSON Rule:
{"name":"Review","pattern":"PR-(\\d+)","titleTemplate":"Review PR-$1","pinned":true,"tags":"#pr","favorite":true}

Productivity

Use the context menu to quick-capture web text. Enable the global shortcut to launch anytime. Save notes silently in the background.

Note Linking

Type [[note-title]] in any note to instantly link to or cross-reference other existing notes.

Reminders

Set precise date/time reminders for follow-ups. Customize notification actions like snooze or auto-dismiss.
